# Валера & Даша — сайт

Одна страница, без сборки и зависимостей: открывается двойным кликом по `index.html`.

## Что уже есть

- счётчик «сколько дней вместе» с 12 июля 2026 (считает сам, в реальном времени);
- галерея с рамками под фото;
- список песен с номером, названием, исполнителем и заметкой;
- таймлайн моментов;
- минимализм: тёмная база, один тёплый акцент, без градиентов, зерна и декоративных анимаций;
- появление блоков при скролле (едва заметное) и адаптив под телефон.

## Как добавить фото

1. Положи картинки в папку `photos/`.
2. В `app.js` впиши имя файла:

```js
photos: [
  { src: "photos/1.jpg" },
  { src: "photos/2.jpg" },
  { src: "" },          // пока пусто — будет рамка
],
```

Пустой `src` = аккуратная рамка-заглушка, ничего не ломается.
Подписи в рамках отключены — только фото.

## Как менять песни

Две колонки — его и её:

```js
songs: {
  him: [
    { title: "Название", artist: "Исполнитель", note: "почему она про него" },
  ],
  her: [
    { title: "Название", artist: "Исполнитель", note: "почему она про неё" },
  ],
},
```

`note` можно оставить пустым — он просто не покажется.

## Как поменять дату

Одна строка в `app.js`:

```js
since: "2026-07-12T00:00:00+03:00",
```

Подпись «с …» подставится сама.

## Как выложить на GitHub Pages

1. Создай репозиторий (например, `us`), **Public**.
2. Загрузи туда `index.html`, `style.css`, `app.js` и папку `photos`.
3. `Settings → Pages → Source: Deploy from a branch → main / (root) → Save`.
4. Через минуту сайт будет на `https://<ник>.github.io/us/`.

## Мелочи

- Шрифты системные — работает офлайн, ничего не грузится из интернета.
- Все тексты только в `app.js`, в `index.html` лезть не нужно.
- Если нужно поменять цвета: переменные в начале `style.css` (`--accent`, `--bg`, `--ink`).
